# 安全 Group-By 聚合模块

负责人：成员 A。当前状态：规划阶段，尚无协议实现。

## 模块目标

研究项目论文中的安全分组聚合方法，优先评估 SecretFlow / SPU，完成 count、sum、mean 的最小可运行示例，并支持接收安全 Join 的共享输出。

## 负责范围

- 明确分组过程、秘密共享表示、安全模型和公开信息。
- 实现分组计数、求和与均值；先约定 `count(*)` 语义，如需 `count(column)`，单独定义缺失值处理。
- 均值按组内有效记录的和与计数计算，明确除法、定点精度、空组和零分母处理。
- 处理 Join 填充行的有效性，避免将无效行计入聚合。
- 记录单列/多列分组键、字符串编码、空值、负数、溢出及参与方数量等能力限制。

## 初步输入输出约定

| 项目 | 预期约定，待验证 |
| --- | --- |
| 输入 | 秘密共享表、分组键、聚合配置、有效行掩码（若有）、运行配置 |
| 聚合配置 | 输出指标名、源字段、聚合操作；`count(*)` 不要求数值源字段 |
| 输出 | 共享的分组键及聚合指标、有效组掩码（若有）、输出字段模式 |
| 精度 | 整数计数与求和尽可能精确；均值约定可验证的误差阈值 |
| 恢复 | 本模块默认不主动公开结果，由后端统一控制恢复 |

分组键是否公开、组数量是否公开、输出是否排序及输出容量必须与 C 明确。上述约定不是既有库能力声明。
